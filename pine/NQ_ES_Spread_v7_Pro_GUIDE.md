# NQ/ES Spread v7 Pro — Руководство

Индикатор для парной торговли NAS100/SP500. Таймфрейм: **M15**. Сессия: **01:00–20:00 UTC**.

Направление позиции: **Short NQ / Long ES** (или наоборот — настраивается).

---

## Как читать график

Нижняя панель — **Session Spread**: разница ATR-нормированных движений NAS и SP от открытия сессии.

- Линия стартует около **0** каждую сессию (01:00 UTC)
- Растёт вверх = позиция в плюсе, вниз = в минусе
- **1 единица ≈ $1000** при стандартном сайзинге ($1000 риск на ногу)
- Вне сессии (20:00–01:00) — данных нет

### Уровни на графике

| Линия | Значение | Что означает |
|-------|----------|-------------|
| **+2.0** (зелёная) | TP уровень | Экстремальное отклонение в твою пользу — фиксируй |
| **+1.0** (светло-зелёная) | Exit уровень | Хороший профит — рассмотри фиксацию |
| **0** (белая) | Нейтраль | Спред в равновесии |
| **-1.0** (светло-красная) | Просадка | Позиция в минусе, но не критично |
| **-2.0** (красная) | Deep DD | Глубокая просадка |

### Цвет линии

- **Ярко-зелёный** (> 2.0) — фиксируй немедленно
- **Зелёный** (1.0–2.0) — в зоне профита
- **Светло-зелёный** (0.5–1.0) — лёгкий плюс
- **Серый** (-0.5–0.5) — нейтрально
- **Оранжевый** (-1.0–-0.5) — лёгкий минус
- **Красный** (< -1.0) — просадка

## Когда ВХОДИТЬ

Вход определяется по **Z-equil** (строка 2 в таблице) — это 200-барный z-score спреда. Он медленнее обычного z-score, поэтому его сигналы реже, но значительно качественнее.

### Условия для входа (ВСЕ должны быть выполнены)

| # | Условие | Где смотреть | Почему |
|---|---------|-------------|--------|
| 1 | **Z-equil < -2.0** (или ниже) | Таблица: строка "Z-equil" | Спред отклонился на 2σ — 98.7% вероятность возврата за 4ч |
| 2 | **Режим ≠ TREND** | Таблица: строка "Реверсия" | Должно быть MEAN REV или RANDOM. При TREND mean reversion не работает |
| 3 | **Сессия активна** | Таблица: "● СЕССИЯ" | Вне сессии данные шумные и неликвидные |
| 4 | **Ликвидность HIGH или MED** | Таблица: "Ликв:" | При LOW спред может давать ложные отклонения |

### Качество сигнала

| Z-equil | Таблица показывает | Сила сигнала |
|---------|-------------------|-------------|
| < -2.5 | **ВХОД!** (зелёный) | Сильнейший — 99.8% реверсия. Входи сразу |
| -2.5 ... -2.0 | **ВХОД** (светло-зелёный) | Хороший — 98.7% реверсия |
| -2.0 ... -1.5 | **СКОРО** (жёлтый) | Пока рано. Жди пока z дойдёт до -2.0 |
| > -1.5 | **ЖДИ** (серый) | Нет сигнала |

### Маркеры на графике

- **ВХОД!** (зелёный лейбл внизу) — z_eq пересёк -2.5, сильный сигнал
- **ВХОД** (зелёный треугольник внизу) — z_eq пересёк -2.0, обычный сигнал

## Когда НЕ ВХОДИТЬ

### Абсолютные запреты

| Условие | Где видно | Почему |
|---------|----------|--------|
| **Режим = TREND** | Таблица: "TREND" красным | Спред трендит — mean reversion не сработает. Потеряешь деньги |
| **Таблица показывает "НЕ ВХОДИ"** | Действие (правый верхний угол) | Индикатор обнаружил trending режим |
| **Вне сессии** | "○ вне" в таблице | Нет ликвидности, данные шумные |
| **VIX > 35** | Красный VIX в таблице | Экстремальный страх, спред может не вернуться |

### Осторожность (можно входить, но с уменьшенным лотом)

| Условие | Где видно | Действие |
|---------|----------|---------|
| **Corr < 0.7** | Контекст: "Corr" оранжевым | Пара временно декоррелировалась. Уменьши лот на 50% |
| **Drift > 20%** | Контекст: "drift" | Beta нестабильна. Уменьши лот |
| **Волатильность ВЫСОКАЯ!** | Красная строка "Волатильн." | Уменьши лот на 40-50% |
| **Волатильность ПОВЫШЕНА** | Оранжевая строка | Уменьши лот на 20-30% |
| **VIX 25-35** | Оранжевый VIX | Повышенная нервозность. Осторожнее с размером |
| **Ликвидность LOW** | "Ликв: LOW" красным | Подожди HIGH/MED сессию |

### Календарные запреты (проверяй отдельно)

Не входи в дни:
- **FOMC** (решение по ставке + пресс-конференция)
- **NFP** (Non-Farm Payrolls, первая пятница месяца)
- **CPI** (индекс потребительских цен)
- Крупные earnings FAANG (AAPL, MSFT, NVDA, AMZN, GOOG, META)

## Когда ВЫХОДИТЬ (фиксация прибыли)

Session spread показывает куда движется твоя позиция в ATR-единицах. Выход по уровням spread:

### Основные правила выхода

| Ситуация | Session Spread | Таблица показывает | Действие |
|----------|---------------|-------------------|---------|
| **Экстремум** | > 2.0 | **ФИКСИРУЙ!** | Закрывай немедленно. 99% откатит |
| **Хороший профит** | 1.0–2.0 | **ФИКСИРОВАТЬ** | Фиксируй. $1000+ прибыль |
| **Лёгкий плюс** | 0.5–1.0 | **ПРОФИТ** | Можно подождать или зафиксировать частично |
| **Нейтрально** | -0.5–0.5 | **ДЕРЖАТЬ** | Жди. Спред ещё не разыгрался |

### Стратегия выхода (по бэктесту)

**Лучшая стратегия (PF 1.53 в бэктесте):**
1. Жди пока session spread достигнет **2.0** (TP уровень)
2. После достижения — жди возврат к **1.0** (exit уровень)
3. Когда spread вернулся к 1.0 — **закрывай**
4. Маркер **ВЫХОД** (оранжевый лейбл сверху) появится автоматически

**Альтернативная стратегия (с time cap):**
1. Вошёл по сигналу ВХОД
2. Жди до **2-4 часов**
3. Если за это время session spread не достиг 1.0 — закрывай по рынку
4. Результат: PF 1.39-1.43, но меньше просадка

### Momentum при выходе

Смотри стрелку в строке S.Spread:
- **↘↘** при spread > 1.0 → спред уже разворачивается, закрывай быстрее
- **↗↗** при spread > 1.0 → спред ещё растёт, можно подождать (но не жадничай)

## Управление позицией (просадка)

| Session Spread | Таблица | Действие |
|---------------|---------|---------|
| -0.5 ... 0 | **ДЕРЖАТЬ** | Нормальная флуктуация. Жди |
| -1.0 ... -0.5 | **ПРОСАДКА** | В минусе, но не критично. Half-life ~3.5ч — вернётся |
| -2.0 ... -1.0 | **DEEP DD** | Глубокая просадка, ~$1000-2000 убытка. НЕ паникуй, 98.7% вернётся |
| < -2.0 | **DEEP DD!** | Экстремум. Проверь Corr и Drift. Если Corr > 0.8 — держи |

### Когда закрывать в убыток

Закрывай позицию в минус ТОЛЬКО если:
1. **Режим сменился на TREND** во время позиции — спред может не вернуться
2. **Corr упала ниже 0.6** — пара сломалась
3. **VIX резко вырос > 35** — macro-шок, неопределённость
4. **Session spread < -3.0** И держится там > 2 часов — редкий случай, ограничь убыток

## Расчёт лотажа

ATR Ratio показывает соотношение волатильности NAS/SP. Используй для дельта-нейтральной позиции:

```
Риск на ногу = $1000

NAS лот = $1000 / (NAS_ATR × $/пт)
 SP лот = $1000 / (SP_ATR  × $/пт)

Пример (ATR Ratio = 4.67):
  NAS ATR = 34.8 пт, $/пт = $1.00  → лот = $1000 / (34.8 × 1) = 28.7 → NAS лот ≈ 28.70
  SP  ATR = 7.4 пт,  $/пт = $10.00 → лот = $1000 / (7.4 × 10) = 13.5 → SP лот  ≈ 13.50
```

**Когда пересчитать лотаж:**
- ATR Ratio стал **оранжевым** (отклонение > 15%) — пересчитай
- **Волатильность ВЫСОКАЯ** — уменьши базовый риск с $1000 до $500-600
- После длинных выходных или VIX > 25

Настрой в TradingView для мобильных уведомлений:

| Алерт | Когда | Действие |
|-------|-------|---------|
| **ВХОД: z_eq < -2.0** | z_eq пересёк -2.0 | Готовься к входу |
| **ВХОД!: z_eq < -2.5** | z_eq пересёк -2.5 | Сильный сигнал — входи |
| **S.Spread: TP уровень** | spread достиг 2.0 | Рассмотри фиксацию |
| **S.Spread: ВЫХОД** | spread вернулся к 1.0 после TP | Фиксируй прибыль |
| **S.Spread: Deep DD** | spread < -2.0 | Глубокая просадка. Проверь Corr |
| **Режим → TREND** | variance ratio > 1.3 | Опасно! Не входи / рассмотри закрытие |
| **Режим → MEAN REV** | variance ratio < 0.7 | Хорошие условия для входа |
| **Вола: ВЫСОКАЯ!** | ATR > 1.5× нормы | Уменьши лотаж |

## Чеклист перед входом

1. [ ] **Z-equil < -2.0** (лучше < -2.5)
2. [ ] **Режим = MEAN REV** или **RANDOM** (НЕ TREND)
3. [ ] **Сессия активна** (01:00–20:00 UTC)
4. [ ] **Ликвидность HIGH или MED**
5. [ ] **Corr > 0.8**
6. [ ] **Drift < 20%**
7. [ ] **Волатильность НОРМА** (или ПОВЫШЕНА с уменьшенным лотом)
8. [ ] **VIX < 25** (серый или жёлтый)
9. [ ] **Нет FOMC/NFP/CPI** сегодня
10. [ ] **ATR Ratio синий** (лотаж актуален)

## Чеклист для выхода

1. [ ] **Session spread > 2.0** → фиксируй (или жди возврат к 1.0)
2. [ ] **Session spread > 1.0** после касания 2.0 → маркер ВЫХОД, фиксируй
3. [ ] **Прошло 2-4 часа** с момента входа → закрывай по рынку (time cap)
4. [ ] **Momentum ↘↘** при spread > 1.0 → подтверждение, закрывай быстрее

## Типичная сделка (пример)

```
09:15 UTC — Z-equil = -2.3, режим MEAN REV, ликв HIGH, VIX 18
           → сигнал ВХОД. Открываешь Short NQ + Long ES
           
09:15      Session Spread = -1.2 (позиция уже в лёгком минусе при входе)

10:30      Session Spread = -0.3, таблица: ДЕРЖАТЬ
           → спред возвращается к среднему, ждём

12:00      Session Spread = +1.5, таблица: ФИКСИРОВАТЬ
           → хороший профит ~$1500, можно зафиксировать

12:45      Session Spread = +2.1, таблица: ФИКСИРУЙ!
           → экстремум, фиксируй немедленно

13:15      Session Spread откатил к 1.0
           → маркер ВЫХОД. Если не зафиксировал раньше — закрывай сейчас
```

**Средний результат по бэктесту (2022-2026):**
- ~130-140 сделок в год
- Profit Factor: 1.39-1.53
- Средний профит на сделку: ~$130-140
- Макс. просадка: $8,000-11,000
