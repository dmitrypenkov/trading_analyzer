# NQ/ES v8 — анализ оптимального времени входа/выхода

> Привязано к: `pine/NQ_ES_Spread_v7_Pro.pine`, `pine/NQ_ES_Spread_v8_Pro.pine`
> Скрипт анализа: `scripts/nq_es_time_analysis.py`
> Сырой вывод: `scripts/nq_es_time_analysis_output.txt`

## Источник данных

- **Инструменты:** NAS100 (id=7), SP500 (id=6) из `data/trading.db`
- **Таймфрейм:** M15
- **Период:** 2022-12-20 → 2026-04-10 (≈ 3.4 года, 77 134 баров)
- **Z-score параметры:** lookback 200 баров (50ч ≈ 2.5 сессии), beta_long 24 баров
- **Результаты транслируются на M5** — таймфрейм меняет гранулярность реакции, но не статистику возврата спреда

## Метод

Симуляция: при пересечении `|z|` порога снизу (cross extreme) — открыть позицию против отклонения. Замеряем:
- **BE_REACHED:** z вернулся к 0 — успех
- **STOP_OUT:** z ушёл ещё на 1σ против (например, с -2.5 до -3.5) — неудача
- **TIMEOUT:** ни одно из условий за 24 часа

## 1. Сравнение порогов входа

| `|z|` порог | N сделок | BE% | Stop% | Avg R | Время до BE |
|---|---|---|---|---|---|
| 1.5σ | 1289 | 84.6% | 13.7% | +1.78σ | 6.2ч |
| **2.0σ ★** | **796** | **80.3%** | **18.5%** | **+2.14σ** | **6.1ч** |
| 2.5σ (текущий default v8) | 458 | 70.7% | 27.7% | +2.30σ | 6.1ч |
| 3.0σ | 278 | 56.1% | 42.4% | +2.16σ | 6.3ч |

**Вывод:** **2.0σ — sweet spot.** При 2.5σ R чуть выше (+0.16σ), но stop-out в 1.5× чаще и сделок в 1.7× меньше. При 3.0σ ожидаемая ценность падает (более 40% — стопы).

**→ Рекомендация для v8: снизить `z_entry_strong` с 2.5 на 2.0.**

### Парадокс «open NY» (13:00–14:00 UTC)

**41% всех сигналов** (188 из 458) приходят на 13–14 UTC — но **именно там худший stop-rate** (27–37%).

Объяснение: индикатор находит много экстремумов в этот час (открытие NY = экспансия волатильности → больше |z|>2.5 событий), но «волатильный шок» побеждает «mean reversion» чаще среднего.

**→ Рекомендация: либо игнорировать сигналы 13:00–14:30 UTC, либо ужесточать порог только в этом окне до 2.5σ.**

## 3. Время удержания

Распределение от входа до возврата z=0:

| Порог | % сделок |

| ≤ 1ч | 9.3% |
| ≤ 2ч | 19.1% |
| ≤ 4ч | 36.4% |
| ≤ 6ч | 62.3% |
| ≤ 12ч | 89.5% |

- **P25:** 2.9ч  •  **P50 (медиана):** 5.8ч  •  **P75:** 7.5ч  •  **P90:** 12.2ч

**→ Hard-timeout 12 часов** покрывает 90% случаев. Дальше держать нет смысла — либо прибыль уже взята, либо что-то структурно сломалось.

## 4. Часы выхода (концентрация закрытий BE)

Два пика:
- **19:00–20:00 UTC:** 19% всех BE-закрытий (NY close)
- **02:00–03:00 UTC:** 13% (Asian momentum)

Дневные сделки тянутся до US-закрытия; ночные — до утра London. **Не закрывайте позицию заранее**, если она ещё не дошла до z=0 — статистически большинство дотягивают до этих окон.

## 6. Базовая статистика при пороге 2.5σ (текущий default v8)

- Всего сделок: 458 за 3.4 года ≈ **135 в год**
- BE_REACHED: 70.7% (324)
- STOP_OUT (выход на ±3.5σ): 27.7% (127)
- TIMEOUT/EOD: 1.5% (7)
- Среднее время до BE: 6.1ч (медиана 5.8ч)
- Avg R по всем сделкам: +2.30σ

## Итоговые рекомендации для v8 индикатора

### Срочно
1. **Снизить `z_entry_strong` с 2.5 на 2.0** — главное улучшение, ×1.7 сделок при сравнимом R.

### Опционально
2. **Hour-of-day гейт:** заблокировать или подсветить вход в 13:00–14:30 UTC.
3. **Hard-timeout 12 часов** для in-position — добавить алерт «время вышло, закрывай по любой».
4. **Подсветка часовых зон** в таблице:
   - 03–05, 09–10, 15, 23 UTC → зелёный фон («оптимальное окно»)
   - 13–14, 18, 22, 00 UTC → оранжевый фон («осторожно»)

### Не нужно
- **День недели** — разброс не значим, фильтр не даёт edge.
- **Жёсткий порог 3.0σ** — ухудшает edge (stop-out 42%).

## Применимость к другим парам

Эта статистика — **только для NQ/ES**. Для EUR/CHF, NAS/DAX, EUR/GBP оптимумы могут отличаться (другие сессии, другая природа корреляции). Чтобы получить аналог, прогнать `scripts/nq_es_time_analysis.py` с правкой `NQ_ID, ES_ID` под нужную пару.
